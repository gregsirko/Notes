# Notes App

This app is a simple notepad with a friendly interface. It makes use of straightforward operations, an organic layout, and saves to local storage.

## 📦 Features

- Create notes.
- Save notes.
- Edit notes.
- Delete notes.

## 🚀 Getting Started

### Prerequisites

Browser. Get the repo somehow.

## 🛠️ Usage

Download the repo. Open terminal. Type these in bash.

```bash
# Example
cd your-repo
open index.html
```
